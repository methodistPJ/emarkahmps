# Batas yang diketahui dan gate penerimaan

Status: **release candidate; Google staging dan penerimaan sekolah masih diperlukan**. Kelulusan semua kriteria production belum boleh diberikan.

1. Ujian setempat menggunakan Google-service doubles. Tiada database, login sekolah sebenar, Drive permission, trigger, deployment atau rekod peperiksaan production dibaca/diubah. Masa rangkaian Google, lock contention sebenar, quota dan kadar kegagalan production belum diukur.
2. sessionStorage melindungi refresh tab biasa, bukan storan tahan lama. Menutup tab, browser crash/clear data, mod privacy atau storage quota boleh memusnahkan draf yang belum sampai server. Amaran storage gagal adalah jelas tetapi tidak menjamin pemulihan selepas tab ditutup. Jangan tutup tab ketika belum ada pengesahan simpanan; eksport draf apabila perlu. Eksport mengandungi maklumat pendidikan sensitif, simpan secara peribadi dan padam selepas selesai.
3. Draf diasingkan dengan user/exam/class/subject; tiada penyegerakan draf merentas tab/peranti. SessionStorage boleh disalin oleh browser apabila duplicate tab; versi server dan idempotency masih melindungi write. Sistem tidak boleh mengesan niat yang belum dihantar dalam tab lain sebelum finalization.
4. Draf lebih 8 jam diberi amaran dan dikekalkan untuk semakan; tiada pemadaman automatik kerja belum disimpan. Logout menolak draf pengguna sama yang masih belum diselaraskan. Draf rosak perlu dieksport dan dibuang secara nyata melalui panel pemulihan. Draf pengguna lain tidak ditunjukkan; peranti bersama tetap memerlukan profil/browser yang diuruskan sekolah. Data tempatan tidak dienkripsi.
5. Proof PBKDF2 baseline ialah credential boleh guna semula, bukan nonce challenge sekali pakai. Keserasian dikekalkan; tiada reka bentuk auth baharu atau rotasi pepper. Perlindungan bergantung pada HTTPS, kerahsiaan verifier/pepper dan kawalan akses projek/Sheets. Audience deploy-as-owner baseline dikekalkan; semua data operasi melalui RPC authorization. Penilaian ancaman menyeluruh di Google belum dilakukan.
6. Read dan write metadata kekal di bawah script lock untuk menghalang bacaan separa WAL. Ini menghadkan throughput. Ujian Promise.all menjalankan servis mock secara bersiri; ia tidak membuktikan distributed concurrency atau latency 20 guru serentak.
7. _OPS dan audit tidak dipangkas; lookup TextFinder mengurangkan data yang dipindah ke V8 tetapi masih membuat carian server yang kos sebenarnya perlu diukur. CacheService row hint boleh hilang; ini tidak memadam receipts. _STATE/USERS/master tables masih dibaca setiap request mengikut keperluan. Audit UI masih membaca jadual sebelum mengambil 500 terakhir. Analitik masih menghantar dataset untuk eksport; jadual master/analitik besar memerlukan kajian lanjutan.
8. Sheets WAL tidak menjadikan Drive/Docs transactional. Archive/import boleh meninggalkan fail orphan jika execution mati selepas mencipta fail sebelum rekod commit. Jangan ulang import sejarah/tahun baharu secara membuta tuli selepas timeout atau refresh; semak Drive, audit, status dan next-year marker dahulu. Mutation ledger umum berada dalam memori; hanya autosave marks/remarks mempersistkan request ID merentas refresh.
9. PDF parser menguji bilangan halaman/A4 dan checksum; ini tidak membuktikan semua teks kelihatan atau font/glyph betul. Google Docs export sebenar untuk 12/14 subjek, nama140 aksara, ulasan300 aksara, tulisan Melayu/aksara lain, B&W dan kelas besar belum dilihat. Dokumen sekolah wajib diperiksa sebelum rasmi. Empat murid/checkpoint dan lease sedia ada dikekalkan. Payload download terhad 12MB.
10. Legacy PDF yang sudah COMPLETED sebelum upgrade mungkin tiada fingerprint/validation metadata; compatibility tidak mengesahkan provenance secara retroaktif. Jana semula selepas semakan jika diperlukan. Fail baharu memerlukan snapshot fingerprint untuk reuse; fail bernama sama tanpa metadata ditolak.
11. Cohort exam dibekukan ketika preparation. Murid baharu/pindah/LEFT selepas itu tidak mengubah snapshot exam secara automatik. Ini tingkah laku baseline yang dikekalkan, bukan keputusan dasar baharu. Pentadbir perlu mengurus kes tersebut secara rasmi sebelum memuktamadkan; alat tambah/buang cohort selepas preparation belum disediakan.
12. Desktop/820px iPad/390px mobile diuji dalam Chromium. Safari iPad/iPhone, VoiceOver/TalkBack, penilaian WCAG 2.2 AA menyeluruh, semua kombinasi form dan setiap laluan destruktif belum diuji. Semua tab pentadbir dirender dalam test; ini bukan bukti semua CRUD berjaya di Google. Font web boleh fallback jika tidak tersedia.
13. Quota Google berubah mengikut akaun dan perkhidmatan. Semak [quota rasmi](https://developers.google.com/apps-script/guides/services/quotas) sebelum operasi; jangan anggap nilai quota atau sasaran 1–3s sudah dicapai. Runtime/trigger/conversion dan saiz Sheets tetap menjadi batas.

Gate pelepasan: sahkan salinan staging, fail PDF sebenar, permission, satu trigger, recovery, backup/restore dan smoke tests dalam DEPLOYMENT_GUIDE. Dapatkan penerimaan sekolah untuk cohort dan slip; jangan label production-ready hanya berdasarkan ujian ini.
